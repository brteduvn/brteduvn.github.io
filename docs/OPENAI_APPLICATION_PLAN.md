# Codex for Open Source — evidence plan

**Do not submit yet.** Approval is discretionary and cannot be guaranteed. A newly released project must develop authentic maintenance history, user feedback and contributor activity. Do not fabricate stars, usage, contribution, downloads or test claims.

Collect: owner/maintainer proof (brteduvn), source license, readable README, tagged releases, CI logs, security/privacy policies, contributions/issues/PRs, real usage feedback with consent, version milestones and screenshots/demo, verifiable issues solved. Prepare truthful concise English responses after actual evidence exists. No paid API required for project users. OpenAI application may require manual authenticated submission/consent by repository owner.
