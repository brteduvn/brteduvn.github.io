# EduPlan OSS v0.1.1-rc.2 — automated GitHub prerelease

**Development release candidate, not a finished curriculum validation product.**

## Highlights
- GitHub Actions performs checks on the exact tagged commit, packages the production Web App and publishes a GitHub prerelease.
- Web App, build-info.json, Git tags, checksum manifest and release notes identify each version.
- Official maintainer: brteduvn; contact: **admin@brt.edu.vn**.
- Privacy-first three-step Vietnamese UI: select DOCX/XLSX/CSV/TXT/MD files, review parsed content and export editable DOCX.
- User-supplied DOCX templates support explicit {{title}}, {{content}}, {{school}}, {{subject}}, {{grade}}, {{teacher}} placeholders.

## Quality gates
The release workflow runs **npm ci, TypeScript typecheck, unit tests, npm audit and Vite production build** before GitHub publishes the prerelease. On failure, the release is not published and GitHub Actions provides error logs. Build timestamp is generated by the workflow and included in web.zip.

## Limitations
This release **does not** automatically understand arbitrary Word templates, preserve all complex tables/layout, validate Vietnamese PPCT rules, process scanned PDF files, include on-device AI, or provide full offline PWA behavior. These are roadmap goals. An exported document must be checked by a teacher before official submission. Frontend bundles are not a hosted demo; download files are static Web App assets that require an appropriate local HTTP server.

## Backup & release policy
Source commits and annotated Git tags are retained. Local Dell archive contains a Git bundle, timestamped Web App build and SHA-256 manifests. Mac 2012 backup remains **pending verification**; it must not be represented as complete. No other project is uploaded to GitHub.
