# Contributing / Đóng góp

Thanks for helping educators. Before starting a feature, please open an issue describing user value and reproduce any bugs with anonymized documents. Use a feature branch, small commits, unit tests, and a pull request. Run `npm run typecheck`, `npm test`, and `npm run build` before submitting. Never commit student data, credentials or copyrighted school templates without permission. Follow the code of conduct. We welcome Vietnamese and English reports.
